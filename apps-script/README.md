# Google Apps Script 중계 배포

GitHub Pages → Google Apps Script(HTTPS, JSONP) → 서울시 API(HTTP) 순으로 조회합니다. PC 서버나 유료 호스팅은 필요하지 않으며 Google Apps Script의 실행·외부 요청 한도는 적용됩니다.

## 1. 새 프로젝트 만들기

[Google Apps Script](https://script.google.com/home/start)에서 **새 프로젝트**를 만드세요. 기존 메모 프로젝트는 그대로 둡니다. 하나의 프로젝트에 `doGet`을 두 개 넣으면 충돌하므로 이 파일을 기존 `doGet` 아래에 붙여넣지 마세요.

이 폴더의 `Code.gs` 전체를 새 프로젝트의 `Code.gs`에 붙여넣고 저장합니다.

## 2. 키와 접속 코드 저장

왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 스크립트 속성 추가**에서 아래 세 항목을 입력합니다.

| 속성 | 값 |
| --- | --- |
| `SEOUL_SUBWAY_API_KEY` | 서울 열린데이터광장 지하철 인증키 |
| `SEOUL_BUS_API_KEY` | 공공데이터포털 서울특별시 버스도착정보조회 서비스의 Decoding 키 |
| `DASHBOARD_TOKEN` | 직접 정한 16자 이상의 긴 접속 코드 |

API 키는 코드·GitHub·채팅에 넣지 않습니다. 대시보드에서는 API 키 대신 이 접속 코드만 사용합니다. 접속 코드는 Google 요청 URL에 들어가므로 개인용으로 사용하고 공유하지 마세요.

## 3. 외부 연결 권한 승인

편집기로 돌아와 함수 목록에서 `authorizeAndTest`를 선택하고 **실행**합니다. Google이 요구하는 외부 연결 권한을 승인합니다. 이 함수는 인증키 없이 지하철 서울역 샘플 API에 연결하고 HTTP 상태만 로그에 남깁니다. 실제 두 인증키의 승인 여부를 검사하는 함수는 아닙니다.

`doGet`을 편집기 실행 버튼으로 실행하는 대신 실제 배포 URL로 테스트하세요.

## 4. 웹 앱 배포

오른쪽 **배포 → 새 배포 → 유형 선택: 웹 앱**을 선택합니다.

- 실행 사용자: **나**
- 액세스 권한: **모든 사용자** (로그인 없이 접근 가능)

배포 후 **웹 앱 URL**을 복사합니다. 주소는 `https://script.google.com/macros/s/…/exec` 형식이어야 합니다. `/dev`는 개발자 테스트 전용이며 사용하지 않습니다. Google Workspace 정책상 익명 접근이 불가능하면 이 JSONP 연결 방식도 사용할 수 없습니다.

이후 코드를 수정했다면 **배포 관리 → 수정 → 새 버전 → 배포**해야 기존 URL에 반영됩니다. 속성의 키 값만 바꾼 경우에는 코드 재배포가 필요하지 않습니다. 캐시는 새 키와 분리됩니다.

## 5. 대시보드 연결

GitHub Pages에서 대시보드를 새로고침하고 **설정**을 엽니다.

1. **Apps Script 웹 앱 주소**에 위 `/exec` URL을 붙여넣습니다.
2. **중계 접속 코드**에 `DASHBOARD_TOKEN` 값을 입력합니다.
3. 조회조건을 확인하고 **저장하고 닫기**를 누릅니다.

이전 브라우저 설정의 역·정류소는 유지됩니다. 저장하면 이전 API 키 필드는 브라우저 설정에서 제거되고 중계 설정으로 교체됩니다. 모니터에서도 같은 중계 주소와 접속 코드를 입력하면 됩니다.

## 오류 확인

- 접속 코드 불일치: 스크립트 속성과 화면 값이 동일한지 확인.
- API 키 설정 안내: 두 스크립트 속성 이름·값 확인.
- 중계 연결 실패/응답 지연: `/exec` URL, 익명 접근, 외부 요청 권한 승인, 새 버전 배포 확인. 주소를 직접 열 때 로그인 화면이 나오면 공개 배포 설정 확인.
- Google에서 API 연결 실패: Apps Script 실행 내역에서 외부 서비스 장애 여부 확인. 원본 오류에는 키가 있을 수 있어 화면에는 전달하지 않습니다.
- 조건 일치 정보 없음: 연결 성공 후의 데이터 문제입니다. 현재 20276은 공식 정류소 자료에서 미확인이고, 20726은 신동아정문입니다.

중계는 고정된 두 API만 읽습니다. 전달받은 임의 URL을 요청하지 않습니다. 성공 자료를 150초간 캐시하며, 브라우저의 취소가 이미 실행 중인 Google 요청을 중단시키지는 않습니다.

## 확인 범위

JSONP는 Google의 [Content Service 공식 문서](https://developers.google.com/apps-script/guides/content)에 나온 브라우저 호출 방식입니다. 공개 교통정보 읽기에만 사용하며 Google 계정 정보는 반환하지 않습니다. 배포 절차는 [Web Apps 공식 문서](https://developers.google.com/apps-script/guides/web)를 따릅니다.

저장소 테스트는 Apps Script 서비스의 모의 구현으로 검증했습니다. 사용자 Google 계정에서의 배포, 실제 키 조회, M7 브라우저 연결은 배포 후 확인해야 합니다.
